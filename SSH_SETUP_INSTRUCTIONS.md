# Как проверить SSH-ключ перед сменой пароля

1. В панели хостинга откройте консоль нужного сервера. Сверьте адрес и убедитесь, что в консоли можно выполнять команды с правами администратора. Держите её и текущую рабочую сессию открытыми.
2. На своём компьютере выберите собственный ключ. В PowerShell список открытых ключей покажет `Get-ChildItem "$env:USERPROFILE\.ssh\*.pub"`. Если нужен новый, создайте его командой `ssh-keygen -t ed25519`, выберите свободное имя файла и задайте парольную фразу. Существующий ключ сохраняйте под его текущим именем. На сервер отправляется только файл с расширением `.pub`.
3. Если этот ключ уже используется для подключения, переходите к проверке в шаге 4. Для первоначальной установки используйте команды ниже. Вместо `user@host` подставьте подтверждённую учётную запись и адрес сервера или свой SSH-псевдоним. Сверьте отпечаток ключа сервера с показанным в консоли хостинга. Установка может запросить авторизацию в штатном приглашении SSH. Если единственный доступ к серверу сейчас через консоль хостинга, добавьте строку своего открытого ключа в `~/.ssh/authorized_keys` нужного пользователя через консоль, сохранив существующие записи. Установите права `700` на `~/.ssh` и `600` на файл.

   Windows PowerShell:

   ```powershell
   .\setup-ssh-access.ps1 -Target 'user@host' -PublicKeyPath "$env:USERPROFILE\.ssh\id_ed25519.pub"
   ```

   Linux или macOS с установленным `ssh-copy-id`:

   ```bash
   bash setup-ssh-access.sh user@host ~/.ssh/id_ed25519.pub
   ```

4. **Откройте новое окно терминала** и выполните следующую команду со своим адресом и путём к закрытой части выбранного ключа (имя без `.pub`). Введите парольную фразу ключа, если SSH её запросит.

   ```text
   ssh -o ControlPath=none -o IdentitiesOnly=yes -o PreferredAuthentications=publickey -i ~/.ssh/id_ed25519 user@host
   ```

   В новом окне выполните `id` и `hostname`. Сверьте пользователя и сервер. При использовании отдельной административной учётной записи проверьте права через `sudo -v`. При отказе сохраните первую сессию и консоль, проверьте путь к ключу, пользователя и права файлов.
5. После успешной проверки смените опубликованный пароль в доверенной консоли хостинга командой `passwd root` от администратора. Сохраните новый пароль в личном менеджере паролей. Повторите шаг 4 в новом окне. Затем проверьте историю входов и список разрешённых ключей.
